# 0x06升降负重测试

当前main仅运行升降测试，不初始化/启动左右轴和抓篮流程。
初始化写入PP模式1、限流2.0 A、速度0.2 rad/s、加速度0.2 rad/s²，
开启类型24主动上报并查询确认模式；读取0x7019多圈机械位置。
上电不使能运动，等待请求。首次使能前预置位置目标。

监视 `lift.state`、`lift.result`、`lift.error`、`lift.position_rad`、
`lift.target_rad`、`Motor_Down.speed/torque/temp`。
READY表示初始化成功，不等于实际负重保持已验证。

1. 先空载写 `lift_request=3`，验证协议正方向0.02圈是否为正对金属输出端
   观察的逆时针。默认 `lift_up_direction=1`；若相反设为-1。
2. 方向测试后写 `lift_request=2` 回到原位置，完成状态HOME。
3. 写 `lift_request=1`：从本次位置上升5圈（31.416 rad）。
   0.2 rad/s下约157秒加减速，到位状态HOLDING，保持内部位置闭环使能。
4. 写 `lift_request=2`：下降回本次起点，HOME后继续保持；不自动往返。
5. 写 `lift_request=4`：明确失能，可能掉落负载，禁止用作悬挂负载的常规停止。

运动最大240秒，反馈与多圈位置超过300ms未更新或电机故障则锁存FAULT。
故障只尽力写PP速度0停止轨迹，不自动失能，以免主动释放负载；通信丢失
或电机自身保护时无法保证保持。故障后检查机械并重启，不自动重试运动。
不调用原有RS01_PositionTask处理Motor_Down，避免速度模式参数覆盖位置保持。
周期查询多圈位置50ms，主动帧类型2/0x18更新速度、力矩和温度。

2.0 A是限流设置，不代表保证能提升特定重量。无夹紧/力传感器、硬限位输入、
软行程标定或抱闸控制；先空载确认方向、完整5圈行程及停止，再逐步加负载。
通电保持不是断电防坠，测试用机械支承/防坠措施。运动中不暂停MCU调试。
